# Jayesh Jadhav | Experimental Physicist

Research portfolio covering quantum hardware, thin-film optics, and high-pressure spectroscopy, with research case studies, an experience timeline, a downloadable résumé, and a contact form that creates an email draft.

The layout, typography, transitions, and illustrated crowd are adapted from [Aswin Panengal’s portfolio](https://www.aswinpanengal.me/) with permission. Jayesh's portrait and supporting photographs come from his [published portfolio](https://github.com/jayeshofphysics/JayeshJadhav). The central footer character is an illustration based on that portrait. The Raman spectrum and coplanar waveguide image are illustrative.

## Local preview and publishing

Run `python -m http.server 8000` at the repository root and open `http://localhost:8000`. GitHub Pages serves `main` from the repository root. The site has no build step.

## Features

- `index.html` contains the homepage, project folders, research timeline, contact form, and navigation.
- `research/` presents collaboration areas and case studies in an interactive deck.
- `world/` contains a personal story with a local interactive scene.
- `reference-shell.js`, `reference-motion.js`, and `reference-crowd.js` handle navigation and theme, scroll and hero motion, and the footer crowd.
- `reference-chat.js` provides a local portfolio guide based on Jayesh's published work. It makes no requests when answering a question.
- Space Grotesk is served locally from `assets/reference-fonts/`, with its SIL Open Font License.
